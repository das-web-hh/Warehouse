Исправление HTTP 405 (Share Target) и иконок PWA

Загрузите в КОРЕНЬ сайта (перезапишите старые):
  sw.js, manifest.json, warehouse.html, index.html,
  icon-v2-192.png, icon-v2-512.png, icon-v2-maskable-512.png

ВАЖНО: иконки грузятся именно в корень сайта, РЯДОМ с index.html — а не в
подпапку /icons/. Раньше manifest.json и HTML ссылались на /icons/icon-v2-*.png,
а сами файлы иконок никуда, кроме корня, не заливались — отсюда и не
обновлялась иконка. Теперь все ссылки на иконки указывают на корень
(/icon-v2-192.png и т.д.), как и было при реальной заливке файлов.

Причина 405: при "Поделиться" Android отправляет POST на /upload. Если Service Worker
не активен, запрос доходит до статического хостинга, а тот POST не принимает -> 405.

Что исправлено:
- sw.js v2: ловит POST /upload (и любой POST-переход), всегда отвечает редиректом 303
  на /warehouse.html, GET /upload тоже возвращает в приложение; читает поля file и files.
- Service Worker теперь регистрируется и на index.html (странице входа), с updateViaCache:'none'.
- manifest.json: добавлены id и scope; версия ссылки на manifest поднята до ?v=3,
  чтобы браузер точно перечитал новые пути иконок.
- Пути иконок в manifest.json/index.html/warehouse.html переведены в корень сайта.
- Чтение очереди: записи без файла пропускаются.
- Файл, отправленный через "Поделиться", попадает в модальное окно выбора
  режима приёма (авто / по имени) на странице warehouse.html — окно уже
  реализовано (shareRouteOverlay) и открывается автоматически, как только
  Service Worker сохранит файл и сделает редирект на warehouse.html.

Сервер распознавания (server.py):
- Файлы/страницы накладной отправляются в Gemini строго по одному
  (глобальная блокировка на процесс + пауза между запросами).
- Лимит токенов ответа увеличен до 32768, промпт явно требует не обрывать JSON.
- Если Gemini вернул битый JSON для одной страницы даже после повторных
  попыток, эта страница помечается ошибкой и пропускается (см. поле
  failedPages в ответе), а остальные страницы файла всё равно распознаются —
  раньше сбой одной страницы обнулял весь документ.

ОБЯЗАТЕЛЬНО после загрузки:
1. Удалите установленное PWA Warehouse с телефона.
2. Chrome -> Настройки сайта -> Очистить данные сайта (или откройте сайт и обновите 2 раза).
3. Откройте сайт, войдите (SW установится), затем снова "Установить приложение".
4. Проверка: chrome://serviceworker-internals или DevTools -> Application -> Service Workers:
   должен быть sw.js со статусом "activated".
Работает только по HTTPS.
