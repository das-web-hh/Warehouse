Беспроводной сканер
Выключен · подключите Bluetooth-сканер как клавиатуру
Сопрягите сканер в настройках телефона или компьютера. В приложении отдельное подключение не требуется. После включения откройте «Сканер» и нажимайте кнопку сканирования на устройстве.
Сканер через Wi‑Fi

Введите IP-адрес компьютера, к которому подключён сканер. На компьютере должен работать WebSocket-мост.

Пример: сканер → компьютер → WebSocket на порту 8080 → этот телефон. Bluetooth-сканер выше продолжает работать отдельно.

Python

Укажите адрес Python-сервера. При запуске приложение отправит на него GET-запрос и ожидает JSON-ответ.

Проверять при запуске
Включено · запрос отправляется при открытии страницы

Пример: http://localhost:8050. Сервер Python должен разрешать запросы из браузера (CORS) и возвращать JSON.
